# Stock Burger

แอปนับสต็อกวัตถุดิบร้านสแมชเบอร์เกอร์ ติดตั้งลงมือถือหรือคอมพิวเตอร์ได้ ใช้ออฟไลน์ได้

- นับสต็อกรายวัน คำนวณยอดที่ควรเหลือและส่วนต่างอัตโนมัติ
- ตัดสต็อกจากยอดขาย POS ตามสูตรเมนู
- ต้นทุนต่อเมนู แจ้งเตือนของใกล้หมด รายการสั่งของ (คัดลอก/แชร์ไปไลน์)
- สำรองและนำเข้าข้อมูลเป็นไฟล์ JSON (ข้อมูลเก็บในเครื่องที่เปิดใช้)
